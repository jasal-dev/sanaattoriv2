# Sanaattori

A frontend-only portal for Finnish word games. First game: a Wordle clone with configurable
word length (4–7 letters). No backend — progress and stats are stored in the browser via
`localStorage`.

See [docs/plans/wordle-implementation-plan.md](docs/plans/wordle-implementation-plan.md) for the
full implementation plan.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — typecheck and build for production
- `npm run preview` — preview the production build
- `npm run lint` — ESLint
- `npm run format` / `npm run format:check` — Prettier
- `npm run typecheck` — TypeScript, no emit
- `npm run test` / `npm run test:watch` — unit/component tests (Vitest)
- `npm run test:e2e` — end-to-end tests (Playwright)
- `npm run build:wordlists` — regenerate `src/data/words-{4,5,6,7}.json` from the Kotus source

## Word list data

`src/data/words-4.json` … `words-7.json` are generated by `scripts/build-wordlists.mjs` from
Kotimaisten kielten keskus's (Kotus) [Nykysuomen sanalista
2024](https://kaino.kotus.fi/lataa/nykysuomensanalista2024.txt), filtered down to plain
lowercase Finnish nouns/adjectives/verbs/adverbs of the target lengths. The list is licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) by Kotus.

These files are committed to the repo rather than fetched at runtime, so the app doesn't depend
on kaino.kotus.fi being reachable. Re-run `npm run build:wordlists` to refresh them.
